## Root causes and implementation

`src/dock/Explorer.tsx` previously flattened and replaced rows immediately. It had no motion code, no chevrons or branch drawing, and every icon was a generic folder/note. `MotionFileTree.tsx` now owns the animated rows, retained exits and hover highlight. Explorer preserves lazy directory loading, selection, search, keyboard navigation and source viewing. Search stays flat and immediate. Collections above the desktop's 100-row windowing threshold use fixed-height native virtual rows with row motion disabled; small trees use a single scroll container. There is no added animation timer or per-frame React update.

`src/dock/fileTreeMotion.ts` imports the desktop's exact BeUI easing/spring constants from `apps/desktop/src/lib/beui/ease.ts`. `treeMotionCapabilities()` reads `renderer.getMotionCapabilities()` and can also be opted in with `KYBERN_NATIVE_PHYSICAL_MOTION=1`. The accepted addon lacks these capabilities; its closest existing duration/bounce spring is retained for compatibility. The new native path was **not live-tested** here.

Four places depend on clip7:

1. Chevron `TreeSvg`: raw `<svg motion={...}>`, 0 → 90 degrees, `SPRING_SWAP` (460 / 30 / .55).
2. Folder incoming SVG: ±8 → 0 degrees and opacity, `SPRING_SWAP`.
3. Row height: `SPRING_LAYOUT` (360 / 32 / .6).
4. Hover highlight position: `SPRING_LAYOUT`.

`ProviderMark` previously handled only Claude and Codex; every other provider fell through to the bot glyph. `src/providerMarks.ts` and `src/assets/providers/` now mirror Cursor, OpenCode, Pi, OMP, Devin, Antigravity, Grok and Droid as well. Monochrome marks retain native SVG tinting. OpenCode's two grayscale theme variants and OMP/Antigravity's colours use transparent 128 px rasters rendered from the desktop SVGs, because GPUI's SVG element is a tinted alpha mask. `fileURLToPath` preserves paths containing spaces. The app packager copies these resources. The packaged app itself was not rebuilt in this non-native lane.

`src/nav/TitleBar.tsx` passes the desktop header tone for Codex. `src/native/DiffView.tsx` adds one colour-map export so Explorer reuses the existing file glyphs and colours.
