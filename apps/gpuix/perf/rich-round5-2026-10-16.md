## Changes and source mapping

| Desktop reference | GPUIX implementation |
| --- | --- |
| `views/notes/NoteBody.tsx`, `editorExtensions.ts`, `FormatBar.tsx`, `slashItems.ts` | `src/notes/RichTextarea.tsx`, `RichDocument.tsx`, `NoteEditor.tsx`: always formatted native prose, selection formatting/links, source-preserving edits, native image and table hosts, floating slash menu |

| `components/kit/chat/ComposerEditor.tsx` | `src/composer/TokenTextarea.tsx`, `token-text.ts`, `Completion.tsx`, `src/Composer.tsx`: inline atomic reference labels, raw/source offset conversion, completion transactions, 200-entry/800ms history |
| Existing `lib/markdownParser.ts` unified/remark CommonMark/GFM parser | Five-line exported parse function; `src/notes/rich-text.ts` uses its source-positioned mdast and standard mdast serializers |

The rejected handwritten parser was replaced. Ordinary edits prefer minimal
source patches, including within escaped/entity-containing text. Formatting
serializes the touched parsed prose block. Each result is reparsed before
publication; an unrepresentable cross-boundary edit is restored with an error,
rather than publishing damaged content. Untouched image syntax, link titles and
reference metadata, fences/spans, tables, nested structures and definitions
remain intact in the covered fixtures. Code followed by prose exposes both.

`RichDocument` preserves edited segment identity across source echoes, so Return
and subsequent typing do not discard the new paragraph or its focused buffer.
Images use the existing native `NoteImage`; tables use formatted native cell
inputs. Notes outline tracking is preserved. No native source or binary changed.

Two direct dependencies are exact-pinned to versions already used by desktop:
`mdast-util-to-markdown@2.1.2`, `mdast-util-gfm@3.1.0`. Socket.dev inspection
was attempted via browser and curl; both received HTTP 403.

## Remaining parity gaps

One native document selection/history across virtual Notes blocks or mixed
document segments is still missing. Complex cross-block replacement can be
rejected instead of performed. Exact list/quote nesting and mixed heading
geometry, code-block wash/metrics, inline code monospace, strikethrough paint, inline chip icons/padding,
selection/link bubbles, task-description slash/image insertion and image
resizing remain. Inline images inside prose keep their image host below that
paragraph; this is not exact inline geometry. Native Edit-menu commands and
formatted clipboard HTML are not wired. Real IME and system clipboard
integration are unverified. Composition guards and history handling are
implemented, but synthetic key fixtures do not prove an input method.

A native attributed block-document host remains necessary to close those gaps;
this change does not declare them solved.
