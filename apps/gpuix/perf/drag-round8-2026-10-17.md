# Round 8: retained subtree translation and drag carry

Native retained translation and the drag wiring are implemented; M1 remains
partial on the strict timing gates described below. The desktop board's 1° ghost
tilt remains specified, not implemented. These results exclude scroll8's input-frame draw changes.

## What caused the work

The old carry binding changed a `motion` declaration. That advanced retained-tree
ancestor revisions, notified the root, rebuilt elements, and ran Taffy. Cached row
and navigation islands read the same root entity, so a root notification defeated
otherwise unchanged caches. Round 7 recorded roughly 216 rerenders per row and 320
for the rail across 120 moves.

The first retained-translation app profile found another independent cause:
`scrollEdge` / project `scrollStep` called `scrollToItem` on every display callback
when their integrated offset was already clamped. The native scroll API calls
`invalidate_window` / `window.refresh`, disabling all caches. The separate 8 s
`sample` profile attributes 1,247 of 3,436 main-thread samples to this path. Its
steady list trace recorded 588 renders of every unrelated island. Both callers
now skip a clamped offset that did not move. Real edge scrolling remains enabled.

React and imperative carry share a host. Equivalent fresh `paintTranslate`
objects must preserve the latest native offset. The JS mutation queue remembers
declarations independently of native imperative state, deduplicates equivalent
descriptions, and clears entries on destruction.

## API and implementation

`renderer.setSubtreeTranslation(id, {translateX, translateY})` accepts finite
logical-pixel offsets. A div opts in with `paintTranslate`, containing the existing
`initial`, `animate`, `transition`, and `generation` motion description. Only
`translateX` / `translateY` are supported. `PaintTranslate.tsx` supplies React's
completion-generation guard; `bindNativeCarry` sends the latest pointer directly.

The first installation paints normally. Subsequent changes update native motion
state, retained scene geometry, hitboxes, bounds observations, text-selection/link
layouts, editor caret/IME bounds, and AccessKit node bounds without ancestor
revisions, element construction, listener replacement, or Taffy. Raw masks retain
scope provenance before intersection: outer clips stay fixed and inner clips move,
including clip7's rounded chains. Layout-slot wrappers remain unshifted. Removal,
prop removal, cancellation/landing teardown, and remount discard retained state.

`subtree_translation.rs` drives the existing motion evaluator on native display
callbacks. `subtree_geometry.rs` retains scope/mask metadata, and
`subtree_scene.rs` moves primitives while preserving glyph tiles, shadows, opacity,
and order. `subtree_bounds.rs` / `subtree_a11y.rs` move retained interaction data.
`subtree_translation_hooks.py` and `subtree_translation_gpui.py` reconstruct
the native/GPUI edits.
`apply_hooks.py`, `backdrop_gpui.py`, `patch_js.py`, `update.sh`, the native npm
patch/lock, and the parent-lease handling in `preview-ui-lock.ts` have additive edits.

Task carry, board/list sibling shifts, landing/return, project carry/sibling shifts,
and drop-indicator movement use retained translation with their original curves.
The project ghost's existing lift/shadow remains. No input-event coalescer was added.

Immutable scope/mask provenance is shared by primitives using `Arc` and is
translated once per context. Scene-buffer retention was tested and removed after
a run with worse sidebar timing and growing footprint; that run remains archived.
This implementation still reconstructs scene arrays through `Scene.replay` and
`Scene.finish`; it does not rebuild the element tree. `finish` advances
`paint_generation`, safely rebuilding a region renderer's retained target when a
loader and translation run together. Recording old/new damage and retaining typed
primitive slots could reduce this remaining CPU/GPU work. The existing shader
pipeline has no arbitrary subtree rotation: the desktop's 1° tilt needs rotated
quads, glyph/path transforms, rotated clips, and inverse hit coordinates.
