# Horizontal pull request tabs (ADE-96), 2026-10-31

The horizontal PR body lacked the outer `PR_SCROLL_LAYOUT` boundary already present on the global Pull requests page. A wheel frame consequently rebuilt and laid out the surrounding PR tree, including the large native diff. `tabs/Body.tsx` gives horizontal PRs the same boundary. It also measures the real available width before mounting the detail, avoiding an initial compact/wide remount that discarded restored reading anchors.

## Behavior and bounds

- The + menu opens a searchable PR picker across every known merged network project, independently of the active Space. It lists up to 100 recent PRs per project; a GitHub URL can open another number in a registered repository. Unregistered repository URLs are refused.
- Group-member paths qualify PR identity and every PR RPC. Two member repositories' #108 values are distinct tabs; opening an existing target focuses it. Project calls continue through `prCall` / `projectClient` to the owning daemon, including remote-only projects.
- The global PR list's explicit **Open in tab** action opens beside the selected conversation; ordinary list selection stays on the page. With no existing conversation, the action asks the reader to open one first.
- Inactive PR bodies unmount. Small section/file/filter/expansion values, loaded timeline/file page extents and exact native logical scroll anchors are kept for the last 80 views, with at most 12 viewport/file anchors per view. Summary waits for its worker-parsed native Markdown before restoring. Files and Timeline wait for actual rows. No wheel reconstruction or retained inactive diff tree is used.
- Active detail mounts revalidate through the owning client, keeping unchanged cached detail identities. Eight details and eight Timeline histories are bounded caches; Timeline reuse expires after 30 seconds. Restoring a later-page anchor first rehydrates its saved cursor-page extent, bounded by `TIMELINE_LIMIT`; a saved file from a later metadata page is fetched before fallback selection or file-list anchor restoration. Existing file metadata/page caches remain bounded. Refresh/head changes invalidate page data; remote reconnection retries active reads.
- Exact diff anchors use the additive native renderer support from fork `b99f89d2efb1ae24a9714a5de1cb20f1b43d63f2`, with zed `9bededa33fd6cb33607fa4c2514bbc4f838bc974`. Native implementation/checks and pin integration belong to the parent/native lane.

## Measurement method

`src/pulls/verify.tabs.ts` drives an actual 1440×900 GPUIX window with an isolated in-memory RPC server and scratch client/data directories. No normal daemon or GitHub data is mutated. Apple M1, macOS 27.0.1, Bun 1.4.0, the patched release addon from the pinned fork above; opaque dark appearance, ordinary motion. Three controlled pairs use the same candidate code and addon: `--baseline` disables only the missing outer PR boundary (`KYBERN_PR_TAB_ISLANDS=0`), and the other run enables it. This isolates the layout fix, rather than comparing different data or native builds.

Each run includes 100 wheel packets in Summary, diff, and Timeline; eight file selections; ten chat/PR alternations; and another 300 Summary wheel packets with a hidden chat receiving up to 100 text deltas every 50 ms. The bounded stream prevents an intentionally regressed control from accumulating unlimited work. Summary has 40 formatted sections, the diff fixture has 30 files with 2,400-line patches (600 initially exposed), and Timeline has 30 formatted comments/reviews. Hidden-stream totals differ because the same input sequence completes sooner with the fix; raw reports record the delivered count.

CPU comes from process CPU time over each workload. Render and layout costs are native diagnostic samples. Frame intervals use native frame timestamps; continuous-scroll percentiles retain long stalls. Switching percentiles exclude idle gaps of 250 ms or more. These timestamps and native dispatch-to-paint diagnostics are CPU scene/submission proxies, not physical display fences. File latency measures the automation click through the painted filename and mounted native diff, excluding the deliberate settling delay. React commit duration and energy were not instrumented and are not inferred from CPU.

A named quiet marker and the shared UI lease isolate the final pairs from other native window checks/builds. Exploratory measurements from the earlier reused `ade-ui-freeze` addon (exact original `9eeb1ee` pin) are separate from the final acceptance pairs.
