# Round 7: rounded overflow and Explorer motion

R3-4 and R3-5 were renderer failures. GPUI's content mask carried only a
rectangle: a parent's rounded border did not constrain descendants. Workspace
fills, dock/sidebar children, code body backgrounds, glyphs, images and cached
primitives could therefore cover the transparent part of a rounded corner.
Adding another border did not solve this. The old `rounded-lab.tsx` tests rounded
**inline input decoration backgrounds**, not subtree overflow clipping.

The macOS patch now carries a rounded ancestor chain through layout, paint,
scene replay and hit testing. Coverage is evaluated analytically in existing
fragment passes. It adds no per-frame clip render target or composition pass.
The patch also rounds native webview masks and their hit-test regions. Other
platform renderers have not been ported or verified.
In particular, the expanded `ContentMask` changes native primitive record sizes:
WGPU's packed WGSL/WebGL records must be ported before reusing the disposable
patched GPUI tree with WGPU. The app's local-addon loader is restricted to macOS
arm64, so other platforms continue to use the unchanged npm native binary.

## Explorer API

```tsx
renderer.getMotionCapabilities?.()
// { rotate: true, physicalSprings: true }

<motion.svg
  source={chevronSvg}
  initial={false}
  animate={{ rotate: open ? 90 : 0 }}
  transition={{ type: 'spring', stiffness: 360, damping: 32, mass: 0.6 }}
/>
```

`rotate` means SVG rotation about its centre, in degrees. It does not advertise
div-subtree rotation. Raw `<svg motion={{ initial, animate, transition }}>`
also works. The second requested spring is 460/30/0.55. Physical parameters are
finite positive numbers (at most 1e6); omitted values default to 100/10/1 when
any physical parameter selects this form. Rest uses displacement **and** speed,
so an oscillation's first zero crossing does not truncate the motion. Reduced
motion consumers use `{ duration: 0 }`. React dependencies include all physical
parameters and rotate, and `motion.svg` uses the existing presence lifecycle.
